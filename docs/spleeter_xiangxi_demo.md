# 素材二演示：sherpa-onnx Spleeter 2-stems fp16 — 《血色湘西·华夷之辩》

> 演示时间：2026-09-02
> 模型：sherpa-onnx Spleeter 2-stems fp16（vocals + accompaniment 双 U-Net，与真机 App 内完全相同的模型与参数）
> 处理流程：ffmpeg 提取音轨(mono/44100) → STFT(N_FFT=1024/hop=256/Hann) → 双模型推理 → iSTFT → 混音 `人声×1.0 + 伴奏×gain`

## 一、关键发现：Spleeter 2-stems 对影视对白分离不稳定

**结论**：该影视对白素材 17 段中仅 1 段（140-150s）人声保留良好，11 段人声被严重遗漏（占比<25%）。
Spleeter 2-stems 是在**音乐/歌曲**数据上训练的分离模型，对"影视对白 + 背景音乐"混音（BGM 低频铺底 + 人声中频 + 对白混响环境）鲁棒性明显不足。

## 二、最佳段正式演示（140-152s，人声主导）

提取 140s 起 12 秒，完整跑真模型分离 + 混音：

| 指标 | 数值 |
|------|------|
| 原始混音 RMS | -13.0 dB |
| 分离人声 RMS | **-10.5 dB**（完整保留） |
| 分离伴奏 RMS | -13.1 dB |
| 处理后 gain=0.1 RMS | -10.5 dB |
| 处理耗时 | 3.29s / 12s 音频（RTF=0.27） |

人声能量（-10.5dB）高于伴奏（-13.1dB），BGM 降低到 10% 后对白完整保留。

## 三、与《处处吻》（歌曲）对比 — 模型适用边界

| 素材类型 | 人声RMS vs 伴奏RMS | 分离质量 |
|----------|-------------------|----------|
| 《处处吻》歌曲段 | -12.5 vs -11.5（均衡） | ✓ 优秀，人声/伴奏清晰分离 |
| 《血色湘西》对白段 | -10.5 vs -13.1（最优段） | ~ 可用但不稳定 |
| 《血色湘西》全片 | 大部分段人声占比<25% | ✗ 影视对白分离鲁棒性差 |

## 四、工程结论与建议

1. **"降低BGM保留人声"在歌曲类内容上可行且效果佳**（已用《处处吻》验证）
2. **在影视对白内容上，2-stem 音乐分离模型不可靠** —— 降 BGM 会把对白一起削弱
3. **下一步方向**（针对影视对白场景）：
   - 换用 **4-stem 模型**（vocals/drums/bass/other），把 other 轨（对白+环境声）与 music 轨分离后再降 music
   - 或采用 **对白增强/DNS 类模型**（更擅长老化影视语音）
   - 或 **VAD 辅助**：先检测语音活动段，只在非语音段降 BGM（避免误伤对白）
   - 或 **频谱门限法（非神经）**：对 300-3400Hz 语音频段保护，仅对低频/高频 BGM 段做增益
